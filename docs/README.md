## Documentation Standards

1. **Timestamps**: Add `Last Updated: YYYY-MM-DD` to all documents
2. **Diagrams**: Use Mermaid for architecture diagrams
3. **Examples**: Include code examples for all APIs
4. **Screenshots**: Update UI screenshots with each release
